# 20 个客户端身份、任意 7 个参与者

当前实现：每租户最多 20 个不同 ID，已有 ID 重连不增加数量；本轮任意 7 个不同 ID 各成功提交合法 13 张后生成结果。第 8 份拒绝，已提交手牌不替换。局间可以 07 换 12，之后再换回 07，不必删除登记或更换租户。

协议：previous_round_version 表示这个客户端自己上次绑定的版本，不要求等于当前版本减 1。服务端必须检查它和数据库一致并且小于当前版本；旧请求、旧 start_event_id 不能重新编号使用。客户端新局事件冻结目标轮次，不随服务端广播给旧手牌重编号。恢复时服务端已进入更新轮次，则清掉中断前的候选和请求，重新观察发牌前→开局；若服务端仍在本机绑定轮次，仍需真实结束再进入下一局。

同一租户仍应只包含同一场游戏中参与计算的客户端；无房间号/游戏真实局号，服务端不能证明七份来自同一牌局。切换应在局间完成，不能在已接收一份后用另一 ID 替换这份。

自动验证：20 个真实 WebSocket 连接，用生产客户端状态机与隔离服务端，四轮依次 01–07、01–06+12、01–06+12、01–07，所有轮次的 13 张结果逐格正确，结束面板隐藏。客户端 62 项单元测试通过；包括跨轮返回、重启后新鲜开局、错误轮次、完整 13 张限制。未在八个真实游戏账号和 Android 截图链路上重新运行此版。

部署：必须先更新服务端，再安装 0.4.19。老服务端的连续轮次限制会拒绝跨轮返回。此版本不自动替换桌面 jpq.apk，避免服务器未更新时误装。
