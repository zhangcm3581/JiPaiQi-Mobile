# 结果面板显示与隐藏审核（0.4.5）

## 发现并修复

1. 服务端换轮、关闭当前轮次后，面板可能保留；后续仍识别到一键配牌又会显示。修复为立即隐藏并清空结果，直到本机真实结束并确认下一局，禁止旧版本结果重新弹出。
2. 租户停用后再断线，原先仅在在线时检查停用，可能重新显示旧面板。现在停用状态持续有效，断线不会解除。
3. 面板可拖进识别区，遮挡后会触发隐藏，再识别成功又弹出，形成反复切换。现在移动时避开手牌和状态搜索区；区域/方向改变后自动寻找空白处，找不到安全位置则保持隐藏。
4. 界面轮询分别读取可变的结果和显隐状态，存在跨轮组合风险。现在在识别工作线程上同时读取状态、结果和说明，作为一次更新交给主线程。识别状态改变后立即通知界面，不额外等待250毫秒轮询。
5. 面板显示/隐藏复用同一个系统窗口，不再每次创建和移除窗口；关闭时统一释放。
6. 截图流不再返回新帧时，旧面板可能无限停留；超过1.5秒无新截图会隐藏并要求恢复有效画面。

## 最终行为

| 情况 | 面板行为 |
| --- | --- |
| 已确认新局，一键配牌连续出现两帧 | 显示；没有服务器结果时显示等待空网格，绝不沿用上一局牌 |
| 服务器本轮有效结果到达 | 显示13张；不会改变手动隐藏或比牌阶段的隐藏状态 |
| 一键配牌短暂漏识别，小于600毫秒 | 保持显示，避免闪烁 |
| 一键配牌连续消失600毫秒 | 隐藏，不发新局或结束事件 |
| 同局重新摆牌，按钮连续出现两帧 | 恢复同局面板，不重复上报 |
| 继续/返回大厅任一结束特征连续两帧命中 | 隐藏并清空；服务继续采集下一桌 |
| 暂停、旋转、息屏或无效截图 | 隐藏；恢复后重新确认画面 |
| 手动点击隐藏 | 同一阶段的结果/状态刷新不会强行打开；新摆牌阶段可以恢复 |
| 服务端换轮/关闭、租户停用 | 隐藏，拒绝旧结果复现 |
| 网络短暂断开且本局已有有效结果 | 画面仍确认摆牌时保留本局结果；不将断线当作新局 |

200毫秒采样下，两帧确认大约需要200–400毫秒；消失防抖约600–800毫秒，再加识别/绘制开销。这里是设计时序，不宣称实测恒定帧率或零延迟。黑屏/息屏仍优先保证状态安全，不延迟隐藏来掩盖采集故障。

## 0.4.6 用户确认的位置规则（覆盖0.4.5避让规则）
结果面板固定屏幕左上角 x=2、y=2（物理像素），不能拖动，也不自动迁移到其他空白处。滑动不移动且不误触隐藏；点击仍可隐藏。旋转、重现后仍回左上角。若配置识别区与固定位置冲突，保留隐藏保护，不移动面板。控制栏仍可拖动。
