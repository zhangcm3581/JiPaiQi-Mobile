## 修改后的流程

1. 任一本轮参与者报告结束，服务端确认并广播换轮。
2. 客户端收到高于本机旧局的有效轮次，立即隐藏面板、清空旧结果、结束本局，停止重试已关闭版本的旧请求，重新开启手牌识别。
3. 不再等待每台客户端都识别到结束或600毫秒过渡画面。
4. 未观察到本机过渡时，连续两次相同、合法、完整的13张新手牌，且与旧局牌不同，才产生新的请求、新的开局事件并按当前版本提交。
5. 已观察到明确本机过渡时允许相同牌集合的新局。没有过渡且新局恰好完全相同，仍会保守等待，防止旧牌重发。
6. 截图中断或断线清除未完成的连续识别证据。旧结果、旧ACK、旧请求的迟到错误及低版本状态不能重开面板或阻断新局。换轮中未确认完的手牌也列入防重传保护。

不足13张、超过13张、非法牌面、同一牌超过两张都不能上报。暂停断网、身份配置、面板尺寸字体保持原逻辑。
